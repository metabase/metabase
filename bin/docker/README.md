# Getting started
This image contains the open-source version of Metabase. For the Metabase with all of the bells and whistles, check out [Metabase Enterprise](https://www.metabase.com/product/enterprise).

To get started, check out our docs:
- [Running Metabase on Docker](https://www.metabase.com/docs/latest/installation-and-operation/running-metabase-on-docker)
- [Running Metabase in production](https://www.metabase.com/docs/latest/installation-and-operation/running-metabase-on-docker#production-installation)  
  
If you’d prefer Metabase host your instance and application database for you, check out [Metabase Cloud](https://www.metabase.com/pricing).
