# Textarea

Our themed wrapper around [Mantine Textarea](https://mantine.dev/core/textarea/). It shares its border, background, focus, error and disabled styles with `TextInput`.

- Sizes: `sm`, `md` (default) and `lg`.
- Autosizes between `minRows={2}` and `maxRows={6}` by default. Pass `autosize={false}` with `rows` for a fixed height.
