# Radio

Our themed wrapper around [Mantine Radio](https://mantine.dev/core/radio/).

## When to use Radio

Radio buttons allow users to select a single option from a list of mutually exclusive options. All possible options are exposed up front for users to compare.

## Docs

- [Figma File](https://www.figma.com/design/qYbAmJHUJ2Tkb01WFegUKp/Component-Library?node-id=250-13082)
- [Mantine Radio Docs](https://mantine.dev/core/radio/)

## Usage guidelines

- **Use this component when the options are mutually exclusive and users pick exactly one.** For independent options that toggle on their own, use <a href="/?path=/docs/components-inputs-checkbox--docs" target="_top">Checkbox</a> instead.
- **Keep the list short.** Past a handful of options a <a href="/?path=/docs/components-inputs-select--docs" target="_top">Select</a> is easier to scan than a long column of radios.
- For option ordering, try to use your best judgement on a sensible order. For example, Yes should come before No. Alphabetical ordering is usually a good fallback if there's no inherent order in your set of choices.
- In almost all circumstances you'll want to use `<Radio.Group>` (<a href="/?path=/story/components-inputs-radio--groups" target="_top">an example</a>) to provide a set of options and help with defaultValues and state management between them.
