    Properties

    cancelRequest

    cancelRequest: () => void

    Cancel the current in-flight request.

    contextWindowPercentUsage

    contextWindowPercentUsage: number

    How much of the model's context window the conversation occupies, 0-100.

    CurrentChart

    CurrentChart: React_2.ComponentType<MetabotChartProps> | null

    A pre-wired component bound to the latest chart the agent produced. null until the agent sends a chart — lets consumers detect presence and render a placeholder or swap panel content only when set.

    Example

    {CurrentChart ? <CurrentChart /> : <Placeholder />}

    errorMessages

    errorMessages: MetabotErrorMessage[]

    Errors are conversation-level, not attached to individual messages.

    isContextWindowFull

    isContextWindowFull: boolean

    Whether the conversation has consumed its entire context window.

    isProcessing

    isProcessing: boolean

    true from the moment a message is submitted until the response completes — including success, error, or cancellation.

    messages

    messages: MetabotMessage[]

    All messages in the conversation. Chart messages include a Chart property.

    resetConversation

    resetConversation: () => void

    Clear all messages and start fresh.

    retryMessage

    retryMessage: (messageId: string) => Promise<void>

    Rewinds the conversation to the user message preceding messageId and re-submits that prompt. The agent message at messageId and anything after it is dropped.

    submitMessage

    submitMessage: (message: string) => Promise<void>

    Submit a new message to the conversation.
