# Tooltip

Our themed wrapper around [Mantine Tooltip](https://mantine.dev/core/tooltip/).

## Docs

- [Mantine Tooltip Docs](https://mantine.dev/core/tooltip/)

## Behaviour

Once a tooltip opened by hover has finished fading in, it stays open while the pointer is on it, so its content can be selected and links in it clicked ([WCAG 1.4.13](https://www.w3.org/WAI/WCAG22/Understanding/content-on-hover-or-focus.html)). Until then it lets the pointer through, so it doesn't get in the way of a pointer crossing its target. It closes shortly after the pointer leaves both the target and the tooltip. Tooltips with a controlled `opened` prop don't take pointer events.
