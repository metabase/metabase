# Space Invaders marching loop — demo asset

Source: https://classicgaming.cc/classics/space-invaders/sounds

The source identifies these as sounds from Taito's 1978 Space Invaders arcade
game. This loop combines `fastinvader1.wav` through `fastinvader4.wav` from:

- https://classicgaming.cc/classics/space-invaders/files/sounds/fastinvader1.zip
- https://classicgaming.cc/classics/space-invaders/files/sounds/fastinvader2.zip
- https://classicgaming.cc/classics/space-invaders/files/sounds/fastinvader3.zip
- https://classicgaming.cc/classics/space-invaders/files/sounds/fastinvader4.zip

Each sample is padded to 0.4 seconds and concatenated in numerical order. The
result is a 1.6-second mono PCM WAV at 22,050 Hz. Timing is arranged for this demo;
this is not a recording of the original game's dynamic tempo.
