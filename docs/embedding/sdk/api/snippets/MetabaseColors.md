## Properties

<!-- [<snippet properties>] -->

| Property                                                                 | Type                                                           | Description                                                                             |
| :----------------------------------------------------------------------- | :------------------------------------------------------------- | :-------------------------------------------------------------------------------------- |
| <a id="metabasecolors-background"></a> `background?`                     | `string`                                                       | Default background color.                                                               |
| <a id="metabasecolors-background-disabled"></a> `background-disabled?`   | `string`                                                       | Muted background color used for disabled elements, such as disabled buttons and inputs. |
| <a id="metabasecolors-background-error"></a> `background-error?`         | `string`                                                       | Color used for error backgrounds. Defaults to light red.                                |
| <a id="metabasecolors-background-hover"></a> `background-hover?`         | `string`                                                       | Slightly darker background color used for hover and accented elements.                  |
| <a id="metabasecolors-background-light"></a> `background-light?`         | `string`                                                       | Light background color used for some controls like a radiogroup.                        |
| <a id="metabasecolors-background-secondary"></a> `background-secondary?` | `string`                                                       | Slightly muted background color.                                                        |
| <a id="metabasecolors-border"></a> `border?`                             | `string`                                                       | Color used for borders                                                                  |
| <a id="metabasecolors-brand"></a> `brand?`                               | `string`                                                       | Primary brand color used for buttons and links                                          |
| <a id="metabasecolors-brand-hover"></a> `brand-hover?`                   | `string`                                                       | Lighter variation of the brand color. Used for hover and accented elements.             |
| <a id="metabasecolors-brand-hover-light"></a> `brand-hover-light?`       | `string`                                                       | Lightest variation of the brand color. Used for hover and accented elements.            |
| <a id="metabasecolors-charts"></a> `charts?`                             | [`ChartColor`](/docs/latest/embedding/sdk/api/ChartColor.md)[] | Chart colors                                                                            |
| <a id="metabasecolors-error"></a> `error?`                               | `string`                                                       | Color used for error icons and borders. Defaults to red.                                |
| <a id="metabasecolors-filter"></a> `filter?`                             | `string`                                                       | Color used for filters context                                                          |
| <a id="metabasecolors-focus"></a> `focus?`                               | `string`                                                       | Color used to outline elements in focus                                                 |
| <a id="metabasecolors-negative"></a> `negative?`                         | `string`                                                       | Color used to indicate dangerous actions and negative values/trends                     |
| <a id="metabasecolors-positive"></a> `positive?`                         | `string`                                                       | Color used to indicate successful actions and positive values/trends                    |
| <a id="metabasecolors-shadow"></a> `shadow?`                             | `string`                                                       | Color used for popover shadows                                                          |
| <a id="metabasecolors-summarize"></a> `summarize?`                       | `string`                                                       | Color used for aggregations and breakouts context                                       |
| <a id="metabasecolors-text-hover"></a> `text-hover?`                     | `string`                                                       | Color used for some button text on hover                                                |
| <a id="metabasecolors-text-primary"></a> `text-primary?`                 | `string`                                                       | Main text color. Should have the most contrast with the background.                     |
| <a id="metabasecolors-text-secondary"></a> `text-secondary?`             | `string`                                                       | Lighter variation of dark text on light elements.                                       |
| <a id="metabasecolors-text-tertiary"></a> `text-tertiary?`               | `string`                                                       | Muted text color for placeholders and disabled elements.                                |
| <a id="metabasecolors-text-white"></a> `text-white?`                     | `string`                                                       | Color used for white text                                                               |
