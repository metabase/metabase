# ActionIcon

Our themed wrapper around [Mantine ActionIcon](https://mantine.dev/core/action-icon/).

## When to use ActionIcon

- Icon-only actions in toolbars, headers, table rows, and other compact places.
- Always pass `aria-label` (or wrap in a `Tooltip` with a string label) since there's no visible text.

Not to use:

- If the action needs a text label, use `Button`.
- If the button shows a counter or other content next to the icon, use `Button`.

### Selectable

`light` and `subtle` have a selected state. Pass `selected={isSelected}` (and `aria-pressed` for toggle buttons). To force the hover or pressed look, pass `mod={{ hovered: true }}` or `mod={{ pressed: true }}`.
