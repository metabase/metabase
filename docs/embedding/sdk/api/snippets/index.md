## useAction

| Name                                                    | Description                                                                                                                                                                                                                                                                                                                                           |
| :------------------------------------------------------ | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| [useAction](./api/useAction.md)                         | Triggers a pre-existing Metabase action. The first arg is the action's numeric id or its `entity_id` string; supply `TParameters` as the first generic to type the `execute` argument, and optionally `TKind` as the second generic to type the discriminated `result` shape.                                                                         |
| [UseActionResult](./api/UseActionResult.md)             | -                                                                                                                                                                                                                                                                                                                                                     |
| [ActionExecuteError](./api/ActionExecuteError.md)       | Shape of the thrown error captured into the hook's `error` state on a non-2xx response. The hook types `error` as `ActionExecuteError                                                                                                                                                                                                                 | null`, so consumers read its fields directly — no cast needed: |
| [ActionKind](./api/ActionKind.md)                       | Flat public kind union. Maps onto the backend's namespaced `row/*` + `bulk/*` `implicitKind` and the `query` `type` value, but exposes a simpler five-value surface to callers: `create` / `update` / `delete` always refer to a single row, `bulk` covers any bulk variant, and `sql` covers custom SQL actions (the backend's `query`-type action). |
| [ActionResultForBulk](./api/ActionResultForBulk.md)     | Response from any bulk variant — a success flag plus optional counts.                                                                                                                                                                                                                                                                                 |
| [ActionResultForCreate](./api/ActionResultForCreate.md) | Response from a single-row create — the inserted row.                                                                                                                                                                                                                                                                                                 |
| [ActionResultForDelete](./api/ActionResultForDelete.md) | Response from a single-row delete — the affected primary keys.                                                                                                                                                                                                                                                                                        |
| [ActionResultForKind](./api/ActionResultForKind.md)     | Maps an `ActionKind` literal to the discriminated `result` shape. Omit `TKind` (`undefined`) to fall back to the `AnyActionResult` union.                                                                                                                                                                                                             |
| [ActionResultForSql](./api/ActionResultForSql.md)       | Response from a custom SQL action — the affected row count.                                                                                                                                                                                                                                                                                           |
| [ActionResultForUpdate](./api/ActionResultForUpdate.md) | Response from a single-row update — the affected primary keys.                                                                                                                                                                                                                                                                                        |
| [AnyActionResult](./api/AnyActionResult.md)             | Union of every possible response body. Used as the `result` default when `TKind` is omitted, so authors who don't know the action's kind upfront still get TS-narrowable shapes (via `"<key>" in result`) instead of a permissive `Record<string, unknown>` that swallows mistyped reads.                                                             |
