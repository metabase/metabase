# Switch

Our themed wrapper around [Mantine Switch](https://mantine.dev/core/switch/).

## When to use Switch

Use Switch when you have a setting that can be only either on or off, or enabled/disabled. If there are multiple related options in a list that could be selected or chosen, use a checkbox group instead.

## Docs

- [Figma File](https://www.figma.com/design/qYbAmJHUJ2Tkb01WFegUKp/Component-Library?node-id=255-8214)
- [Mantine Switch Docs](https://mantine.dev/core/switch/)

## Usage guidelines

- **There is a single switch size.** The `size` prop is not available; the design system defines one `xs` switch.
- **Prefer the label on the left, with the toggle on the right** (`labelPosition="left"`). This lets users read what the setting is before the control.
- Use `Switch.Group` when several related toggles share one label and description.
