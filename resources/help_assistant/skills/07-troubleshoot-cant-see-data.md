1. Separate the two systems: data permissions (databases and tables) and collection permissions (questions, dashboards, models).
2. Remind them that a person gets the most permissive access across all their groups.
3. If a table is missing for everyone, it's more likely sync or hidden tables than permissions; use the sync skill instead.
