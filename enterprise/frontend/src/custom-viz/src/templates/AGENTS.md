# Agent guide

Metabase custom visualization scaffolded by `npx @metabase/custom-viz init`.
Before any change, read `node_modules/@metabase/custom-viz/dist/skill/README.md`
and follow it (`npm install` first if `node_modules/` is missing).

Running as a subagent with a phase file (`skill/phases/*.md`) → ignore
this guide and the README; follow only your phase file.
