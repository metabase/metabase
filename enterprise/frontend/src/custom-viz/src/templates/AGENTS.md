# Agent guide

This project is a Metabase custom visualization scaffolded by
`npx @metabase/custom-viz init`. Before making changes, read
`node_modules/@metabase/custom-viz/dist/skill/README.md` — the full,
version-matched agent guide ships inside the SDK package (run
`npm install` first if `node_modules/` is missing).

Claude Code users get the same guide wired up as the `custom-viz` skill in
`.claude/skills/`.
