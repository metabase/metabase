# Loader

Our themed wrapper around [Mantine Loader](https://mantine.dev/core/loader/).

## Docs

- [Figma File](https://www.figma.com/design/qYbAmJHUJ2Tkb01WFegUKp/Component-Library?node-id=278-16192)
- [Mantine Loader Docs](https://mantine.dev/core/loader/)

## Sizes

| `size` | Diameter | Ring   |
| ------ | -------- | ------ |
| `xs`   | 12px     | 1.5px  |
| `sm`   | 14px     | 1.75px |
| `md`   | 16px     | 2px    |
| `lg`   | 18px     | 2px    |
| `xl`   | 22px     | 2.5px  |

`md` is the default. Raw numbers and CSS lengths still work as an escape hatch.

## Caveats

- `oval` (the default) is the only type Figma specs, and `dots` is the sole alternative the design system offers. Mantine's `bars` is not part of the API.
