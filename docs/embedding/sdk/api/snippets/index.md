The hook types `error` as `ActionExecuteError                                                                                                                                                                                                                 | null`, so consumers read its fields directly — no cast needed: |
| [ActionKind](./sdk/api/ActionKind.md)                       | Flat public kind union. Maps onto the backend's namespaced `row/*` + `bulk/*` `implicitKind` and the `query` `type` value, but exposes a simpler five-value surface to callers: `create` / `update` / `delete` always refer to a single row, `bulk` covers any bulk variant, and `sql` covers custom SQL actions (the backend's `query`-type action). |
| [ActionResultForBulk](./sdk/api/ActionResultForBulk.md)     | Response from any bulk variant — a success flag plus optional counts.                                                                                                                                                                                                                                                                                 |
| [ActionResultForCreate](./sdk/api/ActionResultForCreate.md) | Response from a single-row create — the inserted row.                                                                                                                                                                                                                                                                                                 |
| [ActionResultForDelete](./sdk/api/ActionResultForDelete.md) | Response from a single-row delete — the affected primary keys.                                                                                                                                                                                                                                                                                        |
| [ActionResultForKind](./sdk/api/ActionResultForKind.md)     | Maps an `ActionKind` literal to the discriminated `result` shape. Omit `TKind` (`undefined`) to fall back to the `AnyActionResult` union.                                                                                                                                                                                                             |
| [ActionResultForSql](./sdk/api/ActionResultForSql.md)       | Response from a custom SQL action — the affected row count.                                                                                                                                                                                                                                                                                           |
| [ActionResultForUpdate](./sdk/api/ActionResultForUpdate.md) | Response from a single-row update — the affected primary keys.                                                                                                                                                                                                                                                                                        |
| [AnyActionResult](./sdk/api/AnyActionResult.md)             | Union of every possible response body. Used as the `result` default when `TKind` is omitted, so authors who don't know the action's kind upfront still get TS-narrowable shapes (via `"<key>" in result`) instead of a permissive `Record<string, unknown>` that swallows mistyped reads.                                                             |
