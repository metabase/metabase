# Sidesheet

A Sidesheet keeps details and settings close to the item you're viewing. It
opens from the right side of the screen, so you can stay in context as you work.

Explore the individual stories in the sidebar to see each layout and theme.

## Show details and settings in context

Use a Sidesheet for information about the current item, such as its description,
history, and relationships. It also works for settings you can change while
viewing the item.

## Choose a width for the content

The default size is `sm` (30rem / 480px). Use `md` for wider content, such as
info panels with tabs. Other available sizes are `xs`, `lg`, `xl`, and `auto`.

## Use the inset layout for a floating panel

Set `offset` to add 16px of space above, below, and to the right of the
Sidesheet, with rounded corners. The inset uses the `lg` spacing token.

## Organize content with cards, pages, and tabs

- Use `SidesheetCard` to group related information and `SidesheetCardSection` to
  divide a card into sections. Card borders separate them from the Sidesheet
  surface.
- Use `SidesheetSubPage` for a second level of settings with back navigation.
- Use `SidesheetTabPanelContainer` with `removeBodyPadding` to scroll tab
  content while keeping the tabs visible.

## Keep Escape focused on the topmost dialog

Set `closeOnEscape={false}` on the Sidesheet while a dialog is open above it. One
press of Escape then closes the topmost dialog.
